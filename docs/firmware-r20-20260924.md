# VT Modem release 20 — 2026-09-24

This release is based on firmware build 51 source commit
`7f9f32eca371b89397eefc186fdcc69b027482db` and addresses failures observed
on a live T99W175 GC.004.

## Fixed

- SMS delete RPC no longer crashes the pinned OpenWrt 25.12 ucode parser.
  Fingerprints are validated by byte-length, even-length and uppercase-hex
  checks instead of the unsupported `{1,512}` regexp quantifier.
- A browser tab carrying a stale SMS write job across a router reboot no longer
  remains permanently blocked by `not_found`. The old observation record is
  cleared without replaying the write. Stale deletes refresh the inbox; stale
  sends retain an explicit duplicate-send warning.
- Radio priority parsing accepts the GC.004 unset forms observed across boot
  states: OK-only, bare/prefixed "Band priority file does not exist", and an
  empty `^BAND_PRI:` field. Modem/transport errors remain unknown rather than
  being converted to an empty priority.
- LTE band operation 2 is treated as the hardware-verified replacement
  operation on GC.004. Exact readback is required; an additive-looking result
  is now rejected instead of being silently reconciled.

## Safety

No QMI WAN lifecycle, USB hotplug, modem power sequencing, cell-lock semantics,
or automatic modem reboot behavior is changed by this release. Radio writes
remain stale-snapshot guarded and require explicit confirmation.
